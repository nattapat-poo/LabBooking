## Overview

Smart Lab Booking System is an enterprise room reservation engine supporting concurrency-controlled (`LockService`) room scheduling across rooms 204–315.

* **Tech Stack:** Google Apps Script (V8) + Google Sheets + Tailwind CSS
* **Architectural Guidelines:** [../../.agents/skills/lab-oops-standards/SKILL.md](../../.agents/skills/lab-oops-standards/SKILL.md) & [../../.agents/skills/gas-best-practices/SKILL.md](../../.agents/skills/gas-best-practices/SKILL.md)
* **Agent Scaffolding:** [`mattpocock/skills`](https://github.com/mattpocock/skills) (`npx skills@latest add mattpocock/skills -a <agent>`)
* **Terminology Directive:** Strict scheduling terminology: "Selected Slots" and "Batch Booking" (see [docs/00_CRITICAL_Terminology_Patch.md](docs/00_CRITICAL_Terminology_Patch.md))
